# Borderus

Минимальное приложение для Windows 10, которое рисует настраиваемую рамку вокруг обычных окон и работает из системного трея.

## Возможности

- два полностью независимых профиля для активного и неактивных окон;
- отдельные толщина, цвета, линия, градиент, анимация, скорость и скругление каждого профиля;
- толщина рамки по умолчанию 1 px, диапазон от 1 до 30 px;
- скругление по умолчанию 4 px;
- рамки соблюдают Z-порядок окон и не проступают через перекрывающие окна;
- синхронизация с системными событиями перемещения без polling-задержки;
- сплошная, пунктирная или точечная линия;
- один цвет, градиент вдоль линии или затухание к краям;
- независимое движение пунктира и цветового градиента по или против часовой стрелки;
- изменение скорости и скругления;
- мгновенное применение и сохранение настроек.
- тёмная тема и встроенная иконка-решётка.

`settings.json` хранится рядом с `Borderus.exe`, поэтому настройки переносятся вместе с папкой приложения.

## Запуск

```powershell
dotnet run --project Borderus.csproj
```

Release-сборка:

```powershell
dotnet publish Borderus.csproj -c Release
```

Закрытие окна настроек скрывает Borderus в трей. Полный выход доступен через контекстное меню значка в трее.
